# A/B Testing Simulator

A Streamlit-based web application for statistical A/B testing.

## Features
- Conversion comparison
- Z-test
- P-value analysis
- Confidence interval
- Lift calculation
- Visualization charts

## Technologies
- Python
- Streamlit
- NumPy
- Pandas
- Matplotlib
- Statsmodels

## Run Project

```bash
pip install -r requirements.txt
streamlit run app.py
```
